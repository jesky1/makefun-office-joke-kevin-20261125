One-line office joke entry for make.fun's "The Funniest Office Joke, Judged Head to Head" bounty, $2 in USDC. The program writes a single joke about office life — one short line, setup first and punchline last — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

`main.ts` validates the joke (1–200 characters, single line, no control characters, no leading/trailing whitespace) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
